# แถบของงานแม่ใช้วันที่ของตัวเอง

**วันที่:** 2026-08-06
**ขอบเขต:** `index.html` — `piSpan()`

## ปัญหาที่ผู้ใช้รายงาน

ตั้งวันบน `BRD01 - Company Structure & General Setup` ไว้ `16/06/2026 → 11/08/2026` แต่แถบไม่เริ่มที่ 16/06 กลับหุบไปตามงานย่อย

จำลองด้วยตัวเลขเดียวกันได้ตรงเป๊ะ **รวมถึงเลข 79% ที่ตรงกับภาพ** ยืนยันว่าเป็นพฤติกรรมเดียวกัน

| | |
|---|---|
| วันที่ตั้งบนงานแม่ | `16/06/2026 → 11/08/2026` |
| งานย่อย | `11/08 → 02/09` และ `02/09 → 18/09` |
| แถบที่แสดงจริง | `11/08/2026 → 18/09/2026` |

## ต้นเหตุ

```js
function piSpan(d){
  var ch=piChildren(d);
  if(!ch.length) return {s:d.s,e:d.e};
  ...
  return {s:ss?fmt(ss):d.s, e:ee?fmt(ee):d.e};
}
```

**พอมีงานย่อยแม้แค่ชิ้นเดียว วันที่ของงานแม่ถูกทิ้งทันที** ใช้เป็นค่าสำรองเฉพาะกรณีที่งานย่อยไม่มีวันที่เลย

## ทางที่เลือก — วันของงานแม่ชนะเสมอ

ผู้ใช้เลือกแบบนี้เอง เหตุผล: **งานย่อยคือกิจกรรมภายในงานนั้น ไม่ใช่ตัวกำหนดขอบเขต** ถ้ามันเกินขอบเขต ผู้ใช้จะปรับเอง

เสนอทางเลือก "รวมทั้งสองช่วง" ไปด้วย แต่ผู้ใช้ปฏิเสธเพราะไม่ตรงกับความหมายที่ตั้งใจ

```js
function piSpan(d){
  if(piDate(d.s)&&piDate(d.e)) return {s:d.s,e:d.e};   // มีวันของตัวเองครบ → ใช้เลย
  var ch=piChildren(d);if(!ch.length) return {s:d.s,e:d.e};
  ...คำนวณจากงานย่อยเหมือนเดิม
}
```

**กติกาเดียวกับที่ใช้กับเฟส** — ค่าที่ตั้งเองชนะ ไม่มีค่อยคำนวณให้ ทั้งสองระดับจึงทำงานแบบเดียวกัน

## ผลกับกรณีต่าง ๆ

| กรณี | ผลลัพธ์ |
|---|---|
| งานแม่มีวันเอง งานย่อยเลยออกไป | ใช้วันของงานแม่ (ที่รายงานมา) |
| งานแม่ไม่มีวันที่ | ถอยไปคำนวณจากงานย่อยเหมือนเดิม |
| งานแม่ครอบงานย่อยอยู่แล้ว | ใช้วันของงานแม่ — เท่าเดิม |
| งานเดี่ยวไม่มีลูก | ไม่เปลี่ยน |

## สิ่งที่ไม่แตะ

**วงเล็บของเฟสยังครอบทุกอย่าง** — คำนวณจาก min/max ของทุกงานในเฟสรวมงานย่อย จึงไม่ได้รับผลจากการแก้นี้ ยืนยันด้วยการทดสอบ 9 กรณีของเฟสที่ให้ผลเหมือนเดิมทุกข้อ

**ความคืบหน้ายังคำนวณจากงานย่อย** (`piCalcProg`) ไม่ได้ถูกขอให้เปลี่ยน และป้ายในหน้าต่างรายละเอียดก็เขียนว่า "จากงานย่อย" อยู่แล้ว จึงยังตรงความจริง
