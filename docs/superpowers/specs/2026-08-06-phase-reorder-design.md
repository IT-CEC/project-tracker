# เลื่อนลำดับเฟสได้

**วันที่:** 2026-08-06
**ขอบเขต:** `index.html` — ลำดับเฟสใน Gantt

## ปัญหา

เพิ่มเฟสใหม่แล้วมันไปอยู่ล่างสุดเสมอ และ**ไม่มีทางย้ายได้เลยหลังจากนั้น** ผู้ใช้จึงเพิ่ม `GAP Analysis` ให้อยู่ต่อจาก `02_Solution Definition (BRD)` ไม่ได้

## ต้นเหตุ

`piAddPhase` หาค่า `order` ที่มากที่สุดแล้วให้ตัวใหม่เป็น `maxo+1`

```js
var maxo=0;Object.keys(m).forEach(function(k){if(m[k].order>maxo)maxo=m[k].order;});
var doc={key:key,name:nm,color:...,order:maxo+1};
```

ตัวใหม่จึงอยู่ท้ายเสมอ **และไม่มีฟังก์ชันไหนในแอปที่แก้ `order` ได้** ลำดับจึงตายตัวตั้งแต่วินาทีที่สร้าง

ค่า `order` ที่ `defaultPhaseDocs` แจกเป็นเลขติดกัน (0–6) ไม่มีช่องว่างให้แทรกระหว่างกลางด้วย

## สิ่งที่ทำ

เพิ่มปุ่ม **เลื่อนขึ้น / เลื่อนลง** บนหัวเฟส

ใช้คลาส `.g-phedit` เดิม จึง**โผล่เฉพาะตอนชี้เมาส์**เหมือนปุ่มเปลี่ยนชื่อและลบ ไม่กินพื้นที่ตอนปกติ

### วิธีคำนวณลำดับใหม่

ไม่ได้สลับค่า `order` ของสองตัวตรง ๆ แต่**เรียงใหม่ทั้งชุด**

1. เรียง key ตามตัวเปรียบเทียบเดียวกับที่ render ใช้ (`order` แล้วตามด้วย key)
2. สลับตำแหน่งสองช่องในอาร์เรย์
3. กำหนด `order = ดัชนีใหม่` ให้ทุกตัว
4. **บันทึกเฉพาะเอกสารที่ค่าเปลี่ยนจริง**

ทำแบบนี้เพราะถ้าข้อมูลมี `order` ซ้ำหรือขาดช่วง การสลับค่าตรง ๆ จะไม่ขยับ แต่การเรียงใหม่จะซ่อมตัวเองให้เรียบร้อย

ในกรณีปกติ (เลขติดกัน สลับกับตัวข้าง ๆ) มีแค่ 2 เอกสารที่ค่าเปลี่ยน จึงเขียนแค่ 2

### ไม่แตะข้อมูลงาน

เขียนผ่าน `piPhSave` ลง `COL_PH` (`pi_phases` / `ap_groups`) เท่านั้น ยืนยันจากการทดสอบว่าคอลเลกชันที่ถูกเขียนมีแค่ `pi_phases`

## ทางที่ไม่เลือก

**ลากเพื่อจัดลำดับ** — โค้ดเยอะกว่ามาก และในตารางที่เลื่อนแนวนอนได้ การลากแนวตั้งชนกับการ scroll ปุ่มขึ้น/ลงตรงไปตรงมาและทดสอบได้แน่นอนกว่า

**เลือกตำแหน่งตอนสร้าง** — แก้ได้แค่เฟสใหม่ ไม่ช่วยเฟสที่มีอยู่แล้วซึ่งก็ย้ายไม่ได้เหมือนกัน

## การตรวจสอบ (ในเบราว์เซอร์จริง)

1. เพิ่ม `GAP Analysis` → อยู่ล่างสุดตามเดิม
2. กดเลื่อนขึ้น 5 ครั้ง → อยู่ต่อจาก `02_Solution Definition (BRD)` ตามที่ผู้ใช้ต้องการ
3. เขียน **2 เอกสารต่อการเลื่อน 1 ครั้ง** ลง `pi_phases` เท่านั้น
4. กดเลื่อนขึ้นที่เฟสบนสุด → ไม่เปลี่ยนแปลง ไม่ error
5. กดเลื่อนลงที่เฟสล่างสุด → ไม่เปลี่ยนแปลง ไม่ error
6. ลำดับที่แสดงบนจอตรงกับลำดับในข้อมูล
7. ปุ่มโผล่เฉพาะตอน hover · ไม่มี JS error
