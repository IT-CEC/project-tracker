# สีของเฟสสื่อสถานะ ไม่ใช่ตัวตน

**วันที่:** 2026-08-06
**ขอบเขต:** `index.html` — ทุกจุดที่ใช้ `PI_PHC`
**ต่อเนื่องจาก:** [2026-08-05-oracle-lane-colors-design.md](2026-08-05-oracle-lane-colors-design.md) · [2026-08-06-phase-summary-bar-design.md](2026-08-06-phase-summary-bar-design.md)

## ที่มา

ผู้ใช้รู้สึกว่าป้ายเฟสในคอลัมน์ซ้าย "สีสันไป" และเข้าใจว่าเขียวหมายถึงเสร็จทุกงาน

## สีเฟสไม่เคยบอกสถานะ — และมันหลอกอยู่จริง

```js
PI_PHC = {'01':'#28cd41','02':'#0a7cff','03':'#ff9500','04':'#af52de',
          '05':'#ff2d55','06':'#5ac8fa','07':'#8e8e93'}
เฟสใหม่: PH_PALETTE[จำนวนเฟส % 10]
```

**เป็นสีประจำตัวที่แจกตามลำดับสร้าง ไม่เกี่ยวกับสถานะ**

หลักฐานจากภาพของผู้ใช้เอง: `01_Planning & Kick-off` เขียวเพราะเป็นเฟสที่ 1 · **`GAP Analysis` ก็เขียว เพราะเป็นเฟสที่ 8 ที่ถูกสร้าง** (`PH_PALETTE[7]='#34c759'`) ทั้งที่มีงานที่ยังไม่เริ่ม

**สองเฟสเขียวเหมือนกัน แต่เสร็จจริงแค่อันเดียว** — การอ่านว่า "เขียว = เสร็จ" จึงเป็นความบังเอิญ

## ความขัดแย้งที่มีอยู่แล้ว

ตั้งแต่ [แถบเฟสตอนหุบ](2026-08-06-phase-summary-bar-design.md) ใช้สีตามสถานะรวม (`piPhRoll`) แต่ป้ายซ้ายยังใช้สีประจำตัว

`GAP Analysis` ตอนหุบจึงได้ **ป้ายเขียว** คู่กับ **แถบเทา** — เฟสเดียวกัน สองสี สองความหมาย

## สิ่งที่ทำ

เพิ่ม `piPhColor(ph)` คืนสีจากสถานะรวมของเฟส แล้วเปลี่ยนทั้ง 5 จุดที่เคยใช้ `PI_PHC`

| จุด | เดิม | ใหม่ |
|---|---|---|
| ป้ายเฟส คอลัมน์ซ้าย | สีประจำตัว | **สถานะรวม** |
| chip เฟสบนการ์ด kanban | สีประจำตัว | **สีกลาง** |
| chip เฟสในตาราง Full Details | สีประจำตัว | **สีกลาง** |
| แถบขั้นเฟส (stepper) | เขียว=ผ่าน · สีประจำตัว=ปัจจุบัน | **สถานะรวม** |
| การ์ด Current Phase | สีประจำตัว | **สถานะรวม** |

**chip สองจุดเป็นสีกลาง ไม่ใช่สีสถานะ** เพราะการ์ดและแถวมีสถานะของตัวเองแสดงอยู่แล้ว การเอาสถานะของเฟสไปใส่ chip ข้าง ๆ จะสับสนว่าสีไหนหมายถึงอะไร — chip ตรงนั้นเป็นป้ายบอกสังกัด ตัวหนังสือทำหน้าที่นั้นพอแล้ว

หลังแก้ **ไม่เหลือการใช้ `PI_PHC` ในการแสดงผลเลย** (ตรวจแล้วนับได้ 0)

## ผลข้างเคียงที่ต้องรับทราบ

**ช่องสีประจำเฟสในข้อมูล (`color`) ไม่มีผลกับการแสดงผลอีกต่อไป** ยังถูกเก็บอยู่ในเอกสารเฟสและยังถูกแจกตอนสร้างเฟสใหม่ แต่ไม่มีใครอ่านไปวาด

ไม่ลบทิ้งเพราะเป็นข้อมูลเดิมที่ไม่ได้ทำอันตราย และถ้าภายหลังอยากได้สีประจำเฟสกลับมาในที่ใดที่หนึ่ง ค่ายังอยู่ครบ

## การตรวจสอบ (เบราว์เซอร์จริง)

1. ป้ายเฟสทั้ง 7 ตรงกับสถานะรวมทุกอัน — `01` เขียว Completed · `02` ส้ม In Progress · ที่เหลือเทา Not Started
2. chip บนการ์ดและในตารางเป็น `#76767a` (`--ink2`) ทั้งคู่
3. แถบ stepper ใช้เฉพาะสีสถานะ — เขียว/ส้ม/เทา
4. การ์ด Current Phase ได้ `#ff9500` ตรงกับสถานะรวมของเฟส 02 (เดิมเป็นน้ำเงิน `#0a7cff` ตามสีประจำตัว)
5. `GAP Analysis` เป็นเทาแล้ว ไม่ใช่เขียวที่ทำให้เข้าใจผิด
6. `PI_PHC[` ไม่เหลือในโค้ด · ตรวจถดถอยทั้งแอปไม่มีอะไรพัง · ไม่มี JS error
