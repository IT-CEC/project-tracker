# เลื่อนลำดับงานย่อยได้

**วันที่:** 2026-08-06
**ขอบเขต:** `index.html` — ลำดับงานใน Gantt
**ต่อจาก:** [2026-08-06-phase-reorder-design.md](2026-08-06-phase-reorder-design.md)

## ปัญหา

เฟสเลื่อนลำดับได้แล้ว แต่**งานภายในเฟสเลื่อนไม่ได้**

งานเรียงด้วย `piKeyRank(_key)` ซึ่งเป็นลำดับการสร้างล้วน — `b0,b1,…` แล้วตามด้วย `a1,a2,…` **ไม่มีฟิลด์ลำดับบนงานเลย** ลำดับจึงตายตัวตั้งแต่วันที่สร้าง

## โมเดล — เพิ่ม `ord` แบบไม่บังคับ

```js
function piOrdOf(d){return d.ord!=null?d.ord:piKeyRank(d._key);}
```

งานที่ยังไม่เคยถูกจัดลำดับใช้ลำดับสร้างเหมือนเดิมทุกประการ **ไม่มีการเติมค่าให้ล่วงหน้า**

`piNorm` เปลี่ยนไปเรียงด้วย `piOrdOf` แทน `piKeyRank` ตรง ๆ · `piTreeOrder` เดินตามลำดับในอาร์เรย์อยู่แล้ว จึงได้ลำดับใหม่ตามไปเอง

## การเลื่อน — สลับเฉพาะสองตัว

```js
var ra=piOrdOf(sib[i]),rb=piOrdOf(sib[j]);
sib[i].ord=rb;sib[j].ord=ra;
```

**เขียน 2 เอกสารเสมอ ไม่ว่าครั้งแรกหรือครั้งไหน**

ตอนแรกเขียนเป็นแบบ "เรียงเลขใหม่ทั้งกลุ่ม" เหมือนที่ทำกับเฟส แต่ทดสอบแล้วพบว่า**ครั้งแรกเขียน 13 เอกสาร** เพราะยังไม่มีงานไหนมี `ord` เลย ทุกตัวจึงถูกกำหนดค่าใหม่หมด

การสลับเฉพาะสองตัวให้ผลเหมือนกันเพราะอันดับที่ได้จาก key ไม่ซ้ำกันอยู่แล้ว การแลกค่ากันจึงเท่ากับสลับตำแหน่งพอดี

## ขอบเขตของการเลื่อน — พี่น้องเท่านั้น

นับพี่น้องจาก `parent` เดียวกัน **และ** `ph` เดียวกัน งานจึงไม่มีทางกระโดดข้ามเฟสหรือข้ามระดับ ทดสอบยืนยันแล้ว

**คิดจากรายการที่ผ่านตัวกรอง** (`filteredPI()`) ไม่ใช่ทั้งหมด — เพราะถ้านับตัวที่ถูกซ่อนด้วย กดแล้วจะเหมือนไม่มีอะไรเกิดขึ้น งานที่ถูกซ่อนยังคงอันดับเดิมไว้ จึงยังอยู่ระหว่างสองตัวที่สลับกัน

## ปุ่ม

วางท้ายชื่องานใน `.g-lab` ใช้ `margin-left:auto` ดันไปชิดขวาของคอลัมน์ 250px และ**โผล่เฉพาะตอนชี้เมาส์** เหมือนปุ่มของเฟส ขนาด 16px เล็กกว่าปุ่มเฟส 18px เล็กน้อยตามลำดับชั้น

`stopPropagation` กันไม่ให้ไปเปิดหน้าต่างรายละเอียด

## การตรวจสอบ (เบราว์เซอร์จริง)

1. เลื่อน `BRD General Accounting` ขึ้น → สลับกับตัวบนถูกต้อง · เลื่อนกลับลง → กลับที่เดิม
2. **เขียน 2 เอกสาร** ลง `pi_tasks` เท่านั้น
3. เลื่อนตัวบนสุดขึ้น / ตัวล่างสุดลง → ไม่เปลี่ยน ไม่ error
4. **เลื่อนงานตัวบนสุดของเฟส 03 ขึ้น → ไม่กระโดดไปเฟส 02**
5. ปุ่ม 2 ปุ่มต่อแถว โผล่ตอน hover
6. ตรวจถดถอยทั้งแอป — ไม่มี panel พัง ไม่มี JS error
