# การ์ด KPI — ดีไซน์ใหม่ ใช้ร่วมกัน 2 หน้า

**วันที่:** 2026-08-04
**ขอบเขต:** การ์ดสรุปด้านบนของ sub-view `#actionView` (รายการงาน) และ `#reportView` (รายงาน 3 ระดับ) ใน `index.html`
**ต่อจาก:** [2026-08-04-report-level-cards-design.md](2026-08-04-report-level-cards-design.md) — เอกสารนี้ปรับหน้าตาการ์ดที่สร้างไว้ที่นั่น และขยายไปหน้ารายการงานด้วย

## ปัญหาที่แก้

การ์ดปัจจุบันเล็ก เกาะอยู่ชิดซ้าย เหลือที่ว่างทางขวาเกือบครึ่งจอ และมีแค่ตัวเลขกับป้ายสั้น ๆ ไม่บอกว่าตัวเลขนั้นหมายถึงอะไร หน้ารายการงานยังกินสองแถวเพราะแยก Civil กับ PS Global คนละแถว

## 1. Card component ใช้ร่วมกัน

สร้างชุดเดียวแล้วทั้งสองหน้าเรียก helper ตัวเดียวกัน — แก้ดีไซน์ทีเดียวมีผลทั้งคู่

```
┌─────────────────────────────┐
│ ╭────╮                      │  ไอคอน 38px กรอบมน 11px พื้น = สีการ์ด 10%
│ │ ▣  │                      │
│ ╰────╯                      │
│ ทั้งหมด · TOTAL              │  ป้าย 11px หนา uppercase สี --ink3
│ 90                          │  ตัวเลข 30px หนา tabular-nums
│ 9 แผนก · นับไม่ซ้ำ            │  คำอธิบาย 11px สี --ink3
└─────────────────────────────┘
```

**Layout:** `grid-template-columns: repeat(auto-fit, minmax(190px, 1fr))` — คอลัมน์กว้างเท่ากันเต็มความกว้าง จอแคบ wrap เอง ไม่ล้น

**คลาสใหม่:** `.kgrid` · `.kcard` · `.kcard-ico` · `.kcard-lab` · `.kcard-val` · `.kcard-cap` · `.kcard-split` · `.kcard-half`
**คลาสเดิมที่ลบทิ้ง:** `.actkpi` (คงไว้เป็น wrapper) · `.actkrow` · `.actkl` · `.actk` · `.actk-sp` · `.actk-v` · `.actk-l` · `.actk.on` · `.actk.clk` — ไม่มีที่อื่นใช้ ตรวจแล้วว่ามีเฉพาะสองหน้านี้

**Helper:**
```
kIcon(name, color) -> <div class="kcard-ico">…svg…</div>
kCard({ico, col, vcol, lab, val, cap, on, fn})            // การ์ดตัวเลขเดียว
kCard({ico, col, vcol, lab, split:[{val,cap,on,fn}, …]})  // การ์ดสองตัวเลข
```
- `col` = สีไอคอน · `vcol` = สีตัวเลข (ไม่ใส่ = สีปกติ `--ink`)
- ใส่ `fn` ทั้งใบ = ทั้งใบคลิกได้ · ใส่ `split` = แต่ละครึ่งคลิกแยกกัน (ใบนั้นไม่มี onclick ของตัวเอง)
- ไอคอนเป็น inline SVG แบบ stroke เหมือนที่แอปใช้อยู่ ไม่โหลดจากภายนอก

## 2. หน้า รายงาน 3 ระดับ — 4 ใบ

| ไอคอน | ป้าย | ตัวเลข | คำอธิบาย | สี |
|---|---|---|---|---|
| list | ทั้งหมด · TOTAL | 90 | `<n> แผนก · นับไม่ซ้ำ` | ไอคอน `#8e8e93` · ตัวเลขสีปกติ |
| activity | OPERATIONAL | 39 | หน้างานรายวัน | `#0071e3` |
| layers | MANAGERIAL | 37 | หัวหน้า/PM รายสัปดาห์-เดือน | `#ff9500` |
| trend | EXECUTIVE | 17 | ผู้บริหาร รายเดือน-ไตรมาส | `#5e5ce6` |

คำอธิบายคัดจากนิยาม 3 ระดับในไฟล์ Excel ต้นทาง (`Operational = หน้างานรายวัน · Managerial = หัวหน้า/PM รายสัปดาห์-เดือน · Executive = ผู้บริหาร รายเดือน-ไตรมาส`) เก็บเป็น constant `RPT_LVCAP` — จำนวนแผนกในคำอธิบายใบแรกคำนวณจาก `rptDepts().length` ไม่ hardcode

การคลิกเหมือนเดิมทุกอย่าง: การ์ดระดับ = toggle ตัวกรองระดับ ไม่แตะตัวกรองแผนก · การ์ดทั้งหมด = `rptClear()` · เชิงอรรถ `.mxnote` ใต้ grid คงไว้

## 3. หน้า รายการงาน — จาก 10 ใบเหลือ 5 ใบ

แต่ละใบถือสองตัวเลขคู่กัน Civil กับ PS Global แทนที่จะแยกเป็นสองแถว

```
┌──────────────────────────┐   ┌──────────────────────────┐
│ ╭────╮                   │   │ ╭────╮                   │
│ │ ▣  │                   │   │ │ ◐  │                   │
│ ╰────╯                   │   │ ╰────╯                   │
│ ทั้งหมด · TOTAL           │   │ กำลังทำ · IN PROCESS      │
│ 44                       │   │  27    │    0            │
│ Civil + PS Global        │   │ CIVIL  │ PS GLOBAL       │
└──────────────────────────┘   └──────────────────────────┘
```

| ไอคอน | ป้าย | ซ้าย / ขวา | สี |
|---|---|---|---|
| list | ทั้งหมด · TOTAL | ตัวเลขเดียว = `ACTS.length` · คำอธิบาย `Civil + PS Global` | ไอคอน `#8e8e93` · ตัวเลขสีปกติ |
| play | กำลังทำ · IN PROCESS | นับ `In Process` ฝั่ง `status` / `status2` | `#ff9500` |
| circle | ยังไม่เริ่ม · NOT STARTED | นับ `Not Started` | `#8e8e93` |
| check | เสร็จแล้ว · DONE | นับ `Done` | `#28cd41` |
| alert | เลยกำหนด · OVERDUE | `actOverdue` / `actOverdue2` | `#ff3b30` |

**การคลิก — ความสามารถเดิมอยู่ครบ:**
- ครึ่งซ้าย → `actKfilter('status', <สถานะ>)` · ครึ่งขวา → `actKfilter('status2', <สถานะ>)`
- ใบเลยกำหนด → `actKoverdue('status')` / `actKoverdue('status2')`
- ใบทั้งหมด → `actClear()` และถือว่า active เมื่อไม่มีตัวกรองสถานะและไม่มีตัวกรองเลยกำหนดฝั่งใดเปิดอยู่
- ครึ่งที่ active ได้คลาส `on`
- สถานะ `On Hold` ไม่มีการ์ด เหมือนเดิม (กรองได้จาก dropdown)

## 4. สิ่งที่ไม่ทำ

- **ไม่มี badge "LIVE"** ตามรูปอ้างอิง — สองหน้านี้ไม่มีอะไรที่ต้องบอกสถานะ realtime เป็นพิเศษ
- ตัวเลขบนการ์ดยังเป็นยอดรวมทั้งชุดเสมอ ไม่เปลี่ยนตาม filter (ทั้งสองหน้า) — ตารางข้างล่างคือตัวที่สะท้อน filter
- ไม่แตะตาราง · filter dropdown · drawer · หน้าอื่น · sub-view อื่น

## 5. ผลต่อความสูง

หน้ารายงาน ~90px → ~140px · หน้ารายการงาน สองแถว ~110px → แถวเดียว ~140px — รวมแล้วใกล้เคียงเดิม แลกกับการ์ดที่อ่านออกและเต็มความกว้าง
